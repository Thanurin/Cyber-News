  • How to install Kali Linux for learning?

1. You have to download a iso file from Kali Linux offical website first before we get start! And choose the Recommended file

2. You have to download a Virtualbox to run your Kali Linux and choose your OS

  • If you use window just choose Windows hosts!
  • If you use Mac OS just choose macOS / Apple Sillicon hosts!
  • Or you can choose macOS / Intel hosts but I recommend the second step

3. The third step you have to install the Virtualbox on your pc first

4. You need to get into the Virtualbox and put in your ISO File to run your Kali Linux Click on New

5. You have to complete your machine name and take your ISO File into the Virtualbox as this image

  • You can change your memory machine size just click on Specify virtual hardware
